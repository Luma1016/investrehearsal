# 웹사이트 디자인안: MY 중심 클린 디자인 (데스크탑 기준)

## 0. 개요
- 컨셉: C안(소셜 피드형)을 정갈하게 다듬은 확정안
- 기본 화면: MY 홈 (로그인 후 첫 화면)
- 톤: 깔끔·정갈·여백 중심, 가벼운 밈/네온 요소 제거
- 타깃: 10~20대, 첫투자자도 헤매지 않는 구조
- 샘플: `designs/my-clean-desktop.html` (1280px), `designs/my-clean-mobile.html` (390px)
- 대응 페이지: `public/dashboard.html → MY 홈으로 개편`, `portfolio.html, history.html, board.html, stocks.html, mypage.html`

## 1. 디자인 토큰
- 배경: `#F7F8FA` / 카드: `#FFFFFF` / 본문: `#111827`
- 보조 텍스트: `#6B7280` / 희미 텍스트: `#9CA3AF` / 경계선: `#E5E7EB`
- 포인트: `#4F46E5` (인디고 1색만 사용) / 포인트 배경: `#EEF2FF`
- 상승: `#15803D` + 배경 `#F0FDF4` / 하락: `#DC2626` + 배경 `#FEF2F2`
- 폰트: Pretendard, Apple SD Gothic Neo, sans-serif
- 자간: 타이틀 -0.3px ~ -0.5px, 본문 0
- 반경: 카드 16px, KPI 14px, 버튼·뱃지 999px, 아바타 원형
- 그림자: 사용 안 함 (1px 보더로 구분)
- 행간: 본문 1.55, 캡션 1.4

### 타이포 스케일
- 프로필 이름: 20px-900
- KPI 숫자: 21px-900
- 패널 제목: 15px-800
- 본문·테이블: 13~13.5px-400/700
- 캡션·라벨: 11~12px-700/800

## 2. 레이아웃 (1280px, 3열)
- 전체: `232px (내비) + 1fr (중앙) + 300px (우측)`, 간격 20px
- 좌·우는 `sticky top 28px`, 중앙만 스크롤되는 느낌으로 배치
- 바깥 여백 28px, 배경과 카드 구분 명확히 유지

### 좌측 사이드바
- 로고 `모의스톡 MY` (MY만 포인트 컬러)
- 내비: MY 홈(선택 상태=검정 배경+흰 글씨), 피드, 종목 탐색, 챌린지
- 하단 MENU: 포트폴리오, 거래내역, 설정
- 선택 상태는 1개만, 나머지는 `#374151` 평문 버튼

### 중앙 메인 (MY 홈 본문)
1. 프로필 헤더: 아바타 56px + 이름 + `Lv.4 · 상위 6%` 뱃지 + 가입일차·리그순위·스트릭 1줄 + 우측 프로필 편집 버튼
2. KPI 4개: 총자산 / 주식 평가액 / 예수금 / 챌린지 순위, 숫자 21px, 증감은 그린·레드 소형 텍스트
3. 자산 추이 패널: 제목 + `최근 14일 · 하루 1회 스냅샷` 캡션 + 우측 전체보기 링크, 2.5px 라인 차트 + 연한 면채움, 그리드 3줄
4. 보유 종목 패널: 테이블 6열 (종목/보유수량/평균단가/현재가/손익/차트 버튼), 손익은 pill 뱃지, 마지막 열 우측 정렬
5. 내가 쓴 글 패널: 카드형 2개, 제목 + 시간·좋아요·댓글 캡션 + 본문 1~2줄

### 우측 레일
1. 진행 중 챌린지: 검정 박스(제목+잔여일+참여수+진행바) + 순위 3행 (1~2위 일반, 내 순위 `#EEF2FF` 하이라이트)
2. 실시간 종목: 종목태그 3개 (이름+현재가 좌, 등락률 우)
3. 하단注記: `기본 화면 = MY 홈 · 수수료 0원 · 시장가 단일가`

## 3. 컴포넌트 명세
- 버튼(주): 검정 배경+흰 글씨, radius 10~14px, 13~15px-800
- 버튼(보조): 흰 배경+1px 보더 `#E5E7EB`, radius 10px 또는 999px
- 뱃지: 상승/하락 pill, 레벨 뱃지(포인트 배경), 순위 하이라이트
- 테이블: 헤더 12px 회색, 행 구분선 `#F1F2F4`, 셀 패딩 상하 13px
- 차트: 선 `#4F46E5` 2.5px, 면채움 18%→0% 그라데이션, 포인트 1개만 강조
- 종목태그: `#F8F9FB` 배경 + 1px 보더 + radius 10px
- 빈 상태: 회색 캡션 1줄로 처리, 일러스트·이모지 남용 금지

## 4. 컬러 사용 규칙
- 포인트 인디고는 로고, 레벨 뱃지, 차트, 내 순위 하이라이트에만 사용
- 상승·하락 컬러는 숫자·pill에만 사용, 배경 면적 넓게 쓰지 않음
- 검정은 선택 내비, 챌린지 박스에만 사용
- 이모지는 아바타·종목 아이콘에만 최소 사용

## 5. 화면별 적용 (MVP 매핑)
- MY 홈 = `dashboard.html` 개편, `GET /portfolio` (총자산·평가액·예수금·보유목록) + `GET /assets` (차트) + `GET /posts?mine` (내 글)
- 보유 종목 테이블 행 클릭 → `stock.html` (상세+매수/매도 모달)
- 자산 추이 전체보기 → `portfolio.html` (요약 카드 + canvas 라인 재사용)
- 내가 쓴 글 → `board.html`, `post.html` 연결
- 우측 챌린지 → `asset_history` 일별 스냅샷 랭킹, 실시간 종목 → `GET /stocks`

## 6. 반응형 원칙
- 1280px 이상: 3열 그대로
- 1024px 이하: 우측 레일을 중앙 하단으로 적층 (챌린지→실시간 종목 순)
- 768px 이하: 모바일안(`my-clean-mobile.html`)으로 전환, 좌측 내비는 하단탭(MY/피드/탐색/챌린지)으로 교체
- 테이블은 모바일에서 카드 리스트로 변환 (종목·수량·손익 3요소만)

## 7. 접근성·검수 체크
- 본문 대비 4.5:1 이상 유지 (`#6B7280` on `#FFFFFF` 준수)
- 선택·포커스 상태는 테두리 진하게, 색만으로 구분하지 않음
- 숫자는 천 단위 콤마 + 원 단위 표기 통일
- 손익은 부호(+/-) + 금액 + 수익률 병기

## 8. 제외 사항
- 다크모드, 밈·네온 장식, CPM 광고 배너, 지정가/예약 주문 UI는 1차 제외
- 이미지 업로드·대댓글·신고함 고도화는 2차로 이관 (설계서 10장 참조)
